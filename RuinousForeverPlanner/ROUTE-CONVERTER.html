Bring a Factoruide route into
Ruinous Forever Planner

Everything here runs locally. No uploads, accounts or external scripts.

  1. Generate a single-character WoW Forever guide in Factoruide.
  2. Use its Share/export option to save a .fgguide file. This converter accepts JSON files, not FGG1 compressed import strings.
  3. Select the file below. Copy the converted text, then open /rfp route in WoW and paste it into Import route.
No file selected.

Advice-only compatibility: ordered quest steps and destination coordinates are retained. Automatic progress is limited to observed quest flags/objectives. Travel, training, purchases and unsupported conditions require manual confirmation. No route simulation or pathfinder is included. Verify quests and destinations in the launch client.

Factoruide is an independent project. Format reviewed October 30, 2026. No upstream guide is bundled as a universally valid leveling route.
